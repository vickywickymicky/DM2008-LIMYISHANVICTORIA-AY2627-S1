# Activity 9a – Mapping Sensors

This activity explores how sensor readings can be mapped to control the behaviour of an output.
I used an ultrasonic distance sensor to control the brightness of an LED. Using the map() function, 
I converted distance readings into brightness values, 
allowing the LED to become brighter as an object moved closer and dimmer as it moved further away. 
I also used smoothing to make the changes in brightness more gradual.
Photos and videos of the Arduino setup and LED interactions are included in the documentation folder.
