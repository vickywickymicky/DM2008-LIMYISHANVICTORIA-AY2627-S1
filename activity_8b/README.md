# Activity 8b – Sensor Check

This activity explores how different sensors can be used to collect inputs from the physical environment using Arduino.
I experimented with three types of sensors: a light sensor, force sensor and ultrasonic distance sensor. 
I connected each sensor individually and used the Serial Monitor to observe how the readings changed when I adjusted the light, 
applied pressure or moved an object closer to the distance sensor. 
This helped me understand how physical interactions can be translated into numerical values.
Photos and videos of the sensor setups and testing are included in the documentation folder.
