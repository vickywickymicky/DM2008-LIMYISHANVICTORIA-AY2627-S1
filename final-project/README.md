## My Pudding Squishie – DD3016 Final Project

## About

Hello Kapi n whomever reading this! My Pudding Squishie is an interactive project made using JavaScript and p5.js by Victoria and Yuna. Users can click, hold and drag a digital pudding to squish it and see how it reacts.

The pudding changes its shape and expressions depending on the interaction. Repeated squishing causes bruises, chocolate dents and smaller puddings to appear. After being left alone, the pudding can regenerate, but once it reaches 100 squishes, it explodes. Hope it helps to relieve some stress for you when you play, as much as the amounts of stress it caused when we wrote it. 

## How to Play

- **Click:** Squish the pudding.
- **Click and hold:** Apply more pressure.
- **Click and drag:** Stretch and move the pudding in different directions.
- **Quick taps:** Tap five times quickly to trigger a hidden reaction.
- **Sound:** Turn the sound effects on or off.
- **Reset:** Start over with a new pudding.

## How to Run

1. Open the project folder in VS Code.
2. Make sure `index.html`, `sketch.js` and the `assets` folder are in the project.
3. Open `index.html` using Live Server or another local server.
4. Interact with the pudding using a mouse or trackpad.
