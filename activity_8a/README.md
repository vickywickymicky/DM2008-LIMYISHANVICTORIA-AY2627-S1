# Activity 8a – Light it Up

This activity introduced me to using Arduino to control LEDs through different methods.

I experimented with four different LED setups: always-on, blinking, fading and a combination of all three. 
I started by connecting an LED directly to the 5V supply, 
before using digital outputs to make an LED blink at regular intervals. 
I then explored PWM to gradually increase and decrease an LED's brightness. 
Lastly, I combined the different behaviours into one circuit.

Photos and videos of the Arduino setups are included in the documentation folder.
