# DM2008-LIMYISHANVICTORIA-AY2627-S1

This repository contains my weekly coding activities and projects for DM2008 Experimental Interaction. Throughout these activities, I explored different concepts in p5.js, starting with basic shapes and gradually moving towards interactivity, functions, object-oriented programming and collision detection.

# Activities in Class

Activity 1a – Simple Creatures

For this activity, I experimented with using basic shapes to create different characters. I started with a simple character inspired by Mickey Mouse before moving on to something more complex, a chameleon. I used shapes such as ellipses, arcs and rectangles, adjusting their positions, sizes and colours to create the characters.

Activity 1b – Learning by Making

For this activity, I experimented with generative art inspired by Georg Nees. I used random values to create rectangles of different sizes, positions and colours on a black canvas. I also added a white circle that follows the mouse movement, allowing me to interact with the sketch while the patterns are being generated. Pressing a key saves the resulting artwork as an image.

Activity 2a – Mode Switch

This activity explores how conditional statements can be used to create different modes within a sketch. I created four modes that can be switched using the number keys, each with different shapes, colours and movements. The first three modes feature moving shapes, while the fourth allows the user to control the position and size of a circle using the mouse.

Activity 2b – Pattern Making

For this activity, I used nested for loops to create a repeated pattern of circles arranged in a grid. I added conditional statements to alternate between two colours and used mouseX to control the size of the circles. Moving the mouse horizontally changes the overall appearance of the pattern.

Activity 3a – Array Sampler

This activity helped me understand how arrays can be used to store and control multiple values. I created an array containing different shape sizes and displayed them across the canvas. Each key press randomises the sizes of the shapes, while the sketch also switches between circles and squares depending on the number of times a key has been pressed.

Activity 3b – One Function Wonder

For this activity, I created a custom flower() function that takes in parameters for its position, size and colour. Instead of writing the same code repeatedly, I could call the function with different values to create multiple flowers across the canvas. This helped me understand how functions can make code more organised and reusable.

Activity 4a – Bake a Cookie

This activity introduced me to using classes in p5.js. I created a Cookie class with properties such as flavour, size and position. I added three different flavours, chocolate, vanilla and strawberry, each with their own colours and toppings. The cookie can be moved around using the arrow keys, while clicking the mouse randomly changes its flavour.

Activity 4b – Objects in Motion

For this activity, I worked with an Agent class to create multiple moving circles on the canvas. Each circle has its own position, size and speed. I added a bouncing function to prevent them from moving outside the canvas, along with gradual colour changes and a pulsing effect. Clicking the mouse creates additional circles, while pressing C clears the canvas.

Activity 5a – Colliding Circles

This activity explores how vectors can be used to control movement and detect collisions between objects. I created two balls that move around the canvas and bounce off its edges. Using the distance between their positions, I added collision detection so that both balls change to random colours whenever they collide.
